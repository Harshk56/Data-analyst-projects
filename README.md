# 🛍️ Customer Shopping Behaviour Analysis

## 📌 Project Overview

This project analyzes **customer shopping behaviour** using transactional customer data to identify purchasing patterns, product preferences, customer demographics, subscription behaviour, payment preferences, and spending trends.

The project follows an end-to-end data analytics workflow using **Python, SQL, and Power BI**, transforming raw customer transaction data into meaningful business insights and interactive visualizations.

---

## 🎯 Project Objectives

- Clean and preprocess customer shopping data.
- Explore customer demographics and purchasing behaviour.
- Analyze purchase amounts across product categories and age groups.
- Compare spending behaviour between subscribers and non-subscribers.
- Analyze discount and promotional-code usage.
- Identify popular products and purchasing patterns.
- Analyze shipping and payment preferences.
- Build an interactive Power BI dashboard.
- Generate actionable business insights from the data.

---

## 📊 Dataset

The dataset contains **3,900 customer purchase records** with **18 attributes**.

### Key Columns

| Category | Columns |
|---|---|
| Customer | Customer ID, Age, Gender, Location |
| Product | Item Purchased, Category, Size, Color, Season |
| Purchase | Purchase Amount, Previous Purchases |
| Customer Behaviour | Subscription Status, Frequency of Purchases |
| Marketing | Discount Applied, Promo Code Used |
| Delivery | Shipping Type |
| Feedback | Review Rating |
| Payment | Payment Method |

## 🗄️ SQL Analysis

SQL was used to answer important business questions from the customer transaction data.

### Business Questions

1. **Revenue by Gender**  
   Compare total revenue generated by male and female customers.

2. **Product & Rating Analysis**  
   Identify high-performing and highly rated products.

3. **Shipping Type Comparison**  
   Compare average purchase amounts between different shipping methods.

4. **Subscribers vs Non-Subscribers**  
   Compare purchasing behaviour and revenue contribution.

5. **Top Products by Category**  
   Identify the most purchased products within each category.
